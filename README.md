# مِشكاة المدرسة

تطبيق ويب مدرسي عربي متجاوب (PWA) لإدارة الطلاب والحضور والغياب والسلوك والملاحظات والتواصل مع أولياء الأمور. يمكن تثبيته على شاشة الهاتف من المتصفح.

## التشغيل والنشر على GitHub Pages

الصفحة الرئيسية هي `index.html` في جذر المستودع. من **Settings → Pages** اختر الفرع `man2027` ومجلد الجذر (`/root`) ثم احفظ. بعد اكتمال النشر سيكون الرابط:

https://odayassfour2-beep.github.io/Oday/

يتطلب تثبيت PWA اتصال HTTPS، وهو متاح على GitHub Pages بعد تفعيل النشر.

## الدخول التجريبي

- اسم المستخدم: `admin`
- كلمة المرور: `admin1234`

غيّر بيانات الدخول من صفحة **إعدادات المدرسة**.

## الخصائص

- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر وقابلة للتثبيت كتطبيق ويب.
- لوحة رئيسية وإعداد اسم المدرسة والعام الدراسي وبيانات دخول الإدارة وتفضيلاتها.
- إنشاء سجلات الطلاب وتعديلها وأرشفتها والبحث فيها.
- استيراد الطلاب وأرقام أولياء الأمور من Excel (`.xlsx` و`.xls`) أو CSV، وتصدير قوائم الطلاب.
- تسجيل حضور وغياب وتأخر الطلاب يومياً وتصدير سجل الحضور.
- تسجيل المخالفات والسلوك الإيجابي والملاحظات التربوية.
- إعداد رسالة للغياب أو السلوك أو ملاحظة مخصصة وفتح WhatsApp أو تطبيق SMS على الجهاز، مع إمكانية نسخ الرسالة.
- تصدير سجلات CSV وأخذ نسخة احتياطية كاملة واستعادتها بصيغة JSON.
- دعم أساسي للعمل دون اتصال عبر Service Worker بعد أول زيارة.

## تنبيه مهم حول الخصوصية والجاهزية

هذه نسخة أولية للعرض والتجربة فقط، تعمل دون خادم أو قاعدة بيانات مشتركة. تحفظ بيانات الدخول والطلاب وأرقام الهواتف في `localStorage` على الجهاز والمتصفح الحالي؛ لا يوجد تشفير أو صلاحيات حقيقية أو مزامنة أو إرسال رسائل تلقائي. بيانات الدخول التجريبية ليست آمنة للاستخدام الفعلي، ولا ترفع بيانات طلاب حقيقية أو حساسة إلى هذه النسخة. Excel يعتمد على تحميل مكتبة SheetJS من CDN، لذا يتطلب استيراده اتصالاً بالإنترنت. فتح WhatsApp أو SMS ينشئ رسالة على جهاز المستخدم ولا يرسلها تلقائياً.

للاستخدام الفعلي في مدرسة، يلزم تطوير خادم آمن وقاعدة بيانات، ومصادقة وصلاحيات متعددة الأدوار وسجلات تدقيق ونسخ احتياطي، والامتثال لقوانين حماية بيانات الطلاب، وربط موفر رسائل رسمي بموافقة المدرسة وأولياء الأمور.
