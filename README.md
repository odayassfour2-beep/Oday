# مِشكاة القرآن

موقع عربي متجاوب لقراءة القرآن الكريم والاستماع إلى التلاوات، مع مشغل صوتي آيةً آية وقائمة محفوظات محلية.

## المعاينة والنشر عبر GitHub Pages

الصفحة الرئيسية هي `index.html` في جذر المستودع. عند نشر الفرع `man2027` من **Settings → Pages**، يكون رابط الموقع:

https://odayassfour2-beep.github.io/Oday/

قد يستغرق النشر بضع دقائق بعد حفظ إعدادات Pages. الموقع ثابت ولا يحتاج إلى عملية بناء؛ يستخدم HTML وCSS وJavaScript، ويحمّل بيانات السور والآيات والتلاوات وقت الاستخدام من واجهة AlQuran Cloud. يلزم اتصال بالإنترنت.

## ما يتضمنه الموقع

- واجهة عربية RTL متجاوبة بتصميم حديث.
- فهرس السور الـ114 والبحث عنها.
- عرض نص الآيات مع تشغيل تلاوة الآية، والتنقل للسابق والتالي والتشغيل المتتابع.
- اختيار عشرة قراء من القراء المشهورين، مع استكشاف الإصدارات العربية المتاحة من واجهة الخدمة.
- التحكم بالتقدم والسرعة ومستوى الصوت وتكرار الآية.
- حفظ الآيات في قائمة محلية ونسخ نص الآية.

## ملاحظة

تُحمّل البيانات الصوتية والنصوص من AlQuran Cloud؛ لذلك يتطلب الموقع اتصالاً بالإنترنت وتوافر الخدمة. أسماء القراء والتلاوات وفق ما توفره الخدمة. المحفوظات تحفظ محلياً في المتصفح فقط. هذا موقع قراءة واستماع وليس مصحفاً مطبوعاً أو بديلاً عن التحقق من المصحف المعتمد.
