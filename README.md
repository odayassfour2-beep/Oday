# مِشكاة | بوابة المدرسة الإلكترونية

واجهة مدرسية عربية متجاوبة مع الهاتف والحاسوب (PWA). تتضمن واجهة عامة للمدرسة وإعلاناتها، ولوحة إدارة للطلاب والصفوف والشعب والحضور والسلوك والعقوبات والعلامات والتقارير.

## النشر على GitHub Pages

الصفحة الرئيسية `index.html` في جذر المستودع. من **Settings → Pages** اختر الفرع `man2027` والمجلد `/root`. بعد النشر يكون الرابط المتوقع:

https://odayassfour2-beep.github.io/Oday/

## الدخول التجريبي

اسم المستخدم `admin`، كلمة المرور `admin1234`. غيّرها من إعدادات المدرسة.

## المزايا المضافة

- واجهة رئيسية عامة بمقدمة قابلة للتحرير وإعلانات تنشرها الإدارة، وزر للدخول إلى لوحة التحكم.
- إدارة الطلاب وأرقام أولياء الأمور، واختيار مقدمة فلسطين (+970) أو إسرائيل (+972) افتراضياً أو لكل طالب.
- صفوف أول إلى سادس جاهزة، مع إمكانية إضافة صفوف وشعب إضافية.
- استيراد Excel/CSV، وتصدير سجل الطلاب، وقالب CSV فارغ، وطباعة السجلات.
- تسجيل الحضور والغياب اليومي.
- سجل مخالفات متدرج: لفت نظر، إنذار أول، إنذار ثانٍ مع تعهد ولي الأمر، إنذار نهائي، ثم نقل من المدرسة. الإجراء المقترح يعتمد على عدد المخالفات السابقة، ويمكن للإدارة تغييره. لكل سجل تقرير للطباعة بتوقيعات ولي الأمر والطالب والإدارة.
- إشعار ولي الأمر اختياري عند تسجيل المخالفة؛ يفتح WhatsApp للمراجعة والإرسال اليدوي ولا يرسل تلقائياً.
- سجل علامات مرن: اسم الامتحان والمادة وعلامة الطالب والعلامة الكلية. المعدل يعرض كنسبة من 100، مع تصدير وطباعة.
- نسخ احتياطي JSON واستعادة البيانات، ودعم PWA أساسي.

## تنبيه الخصوصية والجاهزية

هذه نسخة أولية للعرض وليست نظاماً آمناً للاستخدام الفعلي أو لحفظ بيانات الطلاب الحساسة. لا يوجد خادم أو قاعدة بيانات مشتركة أو تشفير أو صلاحيات حقيقية؛ تُخزن البيانات وكلمة المرور في المتصفح على الجهاز الحالي. الرسائل لا ترسل تلقائياً. يلزم قبل الاستخدام المدرسي الفعلي إنشاء خادم آمن وقاعدة بيانات ومصادقة وصلاحيات ونسخ احتياطي، ومراجعة لائحة الانضباط والقوانين المحلية لحماية بيانات الطلاب. استيراد Excel يعتمد على مكتبة SheetJS من CDN ويتطلب اتصالاً بالإنترنت.
