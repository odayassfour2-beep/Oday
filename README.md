# مدرسة سنجل الأساسية العليا

بوابة مدرسية عربية متجاوبة (RTL) لإدارة الطلاب وأرقام أولياء الأمور، الحضور والغياب، المخالفات، العلامات، والهيئة التدريسية.

## المعاينة والنشر عبر GitHub Pages

الصفحة الرئيسية ه�� `index.html` في جذر المستودع. بعد نشر الفرع `man2027` من إعدادات **Settings → Pages**، ستكون الصفحة عادةً على:

https://odayassfour2-beep.github.io/Oday/

قد يستغرق ظهور التعديلات بضع دقائق بعد تفعيل GitHub Pages. إذا كانت Pages مفعّلة مسبقاً على هذا الفرع، افتح الرابط أعلاه.

## تنبيه أمني وخصوصية

هذه نسخة واجهة أمامية فقط: تُحفظ البيانات في `localStorage` على المتصفح والجهاز الحالي، ولا تتزامن مع أجهزة أخرى ولا توفر حسابات أو صلاحيات دخول أو قاعدة بيانات. رابط Pages عام، لذلك لا تستخدموا هذه النسخة لتخزين بيانات حقيقية أو حساسة للطلاب وأولياء الأمور. لا ترفعوا نسخ JSON الاحتياطية إلى المستودع أو إلى موقع عام. للاستخدام المدرسي الحقيقي يلزم خادم وقاعدة بيانات آمنة، مصادقة وصلاحيات مناسبة، واتصالات مشفرة ونسخ احتياطي مضبوط.

## الميزات

- إضافة الطلاب مع الصف والشعبة واسم ولي الأمر ورقم هاتفه.
- تسجيل الحضور والغياب والتأخر والاستئذان حسب التاريخ.
- سجل المخالفات والإجراءات المتخذة.
- تسجيل العلامات والتقييمات.
- سجل الهيئة التدريسية والموظفين.
- بحث الطلاب، حفظ محلي، وتصدير/استعادة نسخة JSON.
- تصميم عربي متجاوب للأجهزة المختلفة.
